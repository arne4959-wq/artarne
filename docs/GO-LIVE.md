# ก่อนเปิดให้คนทั่วไปเข้า (รายการที่ต้องใช้ข้อมูลจริงของคุณ)

รันตรวจได้ทุกเมื่อ: `npm run check` (เตือน) และ `npm run check:live` (ถ้ายังมีเตือน จะ fail ใช้ก่อนอัปโหลดจริง)

| ต้องเปลี่ยน | ที่ไหน | ทำอย่างไร |
|---|---|---|
| บัญชีรับเงินของเว็บ | `circles.js` → `CONFIG.support` | ใส่ธนาคาร (BCEL/LDB) ชื่อบัญชี เลขบัญชี และไฟล์ QR จริง แล้ว **ลบ `sample: true`** |
| อีเมลติดต่อ | `circles.js` → `CONFIG.contact` | อีเมลจริง จนกว่าจะใส่ ลิงก์ "แจ้งปัญหา" ท้ายหน้าจะถูกซ่อน (ไม่มีลิงก์ที่ไปไม่ถึง) |
| ลิงก์สนับสนุนเว็บ (ถ้ามี) | `circles.js` → `CONFIG.donate` | ลิงก์ https ของหน้าสนับสนุน เว้นว่างได้ ปุ่มจะขึ้น "เร็ว ๆ นี้" |
| นโยบายความเป็นส่วนตัว / เงื่อนไข | `privacy.html`, `terms.html` | ใส่ชื่อผู้ดำเนินการ ที่อยู่ ระยะเก็บข้อมูล แล้วลบย่อหน้า `draft` ให้ผู้รู้กฎหมายอ่านก่อน (ผมไม่ใช่ทนายความ) |
| ข้อมูลศิลปินตัวอย่าง | `artists.js` | ศิลปินตัวอย่างจะซ่อนเองเมื่อมีศิลปินจริง: `npm run pull -- --hide-demo` |
| รูปตำนาน | `legends/` | `npm run pictures` |
| ภาษาลาว | `npm run lao-review` | ส่งไฟล์ที่ได้ให้เจ้าของภาษาตรวจ |

ข้อมูลตัวอย่างทั้งหมดในเว็บมีป้าย SAMPLE กำกับและ QR ตัวอย่างใช้โอนจริงไม่ได้ (ตั้งใจให้เป็นรูปแบบที่ไม่ใช่ QR จริง)

## นับคนเข้าเว็บ (ไม่บังคับ)

ปิดอยู่ตามค่าเริ่มต้น ถ้าอยากรู้ว่ามีคนเข้ากี่คน: สมัคร GoatCounter ฟรี (ไม่ใช้คุกกี้ ไม่เก็บข้อมูลส่วนตัว) แล้วใส่ `analytics: 'https://ชื่อคุณ.goatcounter.com/count'` ใน `CONFIG` ของ `circles.js` และ **ต้องแก้ `privacy.html`** ให้บอกว่ามีการนับผู้เข้าชม (ตอนนี้เขียนว่าไม่มี `npm run check` จะไม่ผ่านถ้าลืม) ระบบข้ามคนที่ตั้ง Do-Not-Track ไว้
