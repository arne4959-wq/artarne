# research/ — งานสัมภาษณ์และตัดสินใจก่อนเปิดขายจริง

โฟลเดอร์นี้ไม่ใช่ส่วนของเว็บ (`tools/dist.mjs` ไม่คัดลอกไปเว็บจริง) เก็บแผนและเอกสารสำหรับเจ้าของเว็บ

## สถานะตอนนี้ (ข้อเท็จจริงที่ผู้ใช้บอก)
- ศิลปิน 10 คน งาน 30 ชิ้น อีเมลใน repo เป็นข้อมูลตัวอย่างทั้งหมด
- ไม่รู้จักศิลปินหรือผู้ซื้อเลย อยู่เวียงจันทน์ พูดลาวได้
- เวลา 1 วันต่อสัปดาห์ ไม่มีงบ มีแต่บัญชีธนาคารส่วนบุคคล
- ยังไม่เขียนโค้ดเพิ่มจนกว่าจะผ่านเกณฑ์สัมภาษณ์

## ไฟล์
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `02-วิเคราะห์แนวคิดและการตัดสินใจ.md` | วิเคราะห์แนวคิด สมมติฐาน H1–H9 เกณฑ์ตัดสินใจ (2.5) และทางเลือก D1–D6 (ผู้ส่งของ ผู้รับเงิน คืนเงิน ค่าธรรมเนียม ประเทศ ช่องทางติดต่อ) |
| `03-คำถามสัมภาษณ์-ภาษาลาว.md` | คำถามศิลปิน 10 ข้อ ผู้ซื้อ 10 ข้อ และกฎตอนสัมภาษณ์ |
| `04-ข้อความทักครั้งแรก.md` | ข้อความทักเป็นลาวและไทย ช่องทางหาคน |
| `sheet-1-ติดตามการทัก.csv` | นำเข้า Google Sheets: ใครถูกทัก ตอบหรือยัง |
| `sheet-2-บันทึกสัมภาษณ์.csv` | หนึ่งแถวต่อหนึ่งคำตอบ |
| `sheet-3-วิเคราะห์ปัญหา.csv` | นับว่าปัญหาไหนเจอบ่อยที่สุด |

นำเข้า CSV: Google Sheets → File → Import → Upload → "Insert new sheet"

## แผน 5 สัปดาห์ (1 วันต่อสัปดาห์ ประมาณการ)
1. อ่านแก้ภาษาลาว ทักศิลปิน/ผู้ซื้ออย่างละ 10 คน **ล็อกเกณฑ์ข้อ 2.5 ก่อนสัมภาษณ์คนแรก**
2. สัมภาษณ์ 3–4 คน จดทันที
3. สัมภาษณ์อีก 3–4 คน ทักเพิ่มถ้าคนตอบน้อย
4. สัมภาษณ์ให้ครบ 10 คน เริ่มสรุปตามตารางวิเคราะห์
5. เทียบกับเกณฑ์: ทำต่อ / ปรับแนวคิด / พัก

## ข้อควรระวัง
- เก็บชื่อจริงและช่องทางติดต่อของผู้ให้สัมภาษณ์ **แยกไฟล์** และไม่ commit ลง repo
- อย่า merge PR #1 เข้า main จนกว่าจะตัดสินเรื่องโฮสติ้ง (GitHub Pages ห้ามเว็บธุรกรรมเชิงพาณิชย์เป็นหลัก ดูหัวข้อความเสี่ยงข้อ 4 ในไฟล์ 02)
- ผมไม่ใช่ที่ปรึกษากฎหมาย/ภาษี ปรึกษาผู้เชี่ยวชาญก่อนเลือก D2, D3, D5
